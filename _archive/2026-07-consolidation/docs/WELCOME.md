# Welcome to the_board

the_board is your local executive strategy room. Submit a strategic objective, and Odyssey coordinates the COO, CFO, CTO, and CMO Agents into a clear, actionable plan.

## Begin here

1. Install the project dependencies and start Ollama with the model configured in `.env`.
2. Start the API with `poetry run dev`.
3. Start the dashboard with `poetry run ui`.
4. Submit a goal, monitor the agents, and review the final executive plan.

Your data remains on your machine. Each plan records its task lifecycle, agent analyses, and final synthesis for transparent review.
